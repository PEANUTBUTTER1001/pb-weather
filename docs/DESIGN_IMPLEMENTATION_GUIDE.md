## 1. 앱 셸 · 내비게이션 골격

### 1.1 Scaffold 구조

- **2026-11-26 DR-004 원본 렌더링 우선 정정**: 실제 원본 앱바 높이 `60px`, 설정 탭에서도 지역 트리거·`설정` 제목·도움말·새로고침 동시 노출 확인. 아래 초기 명세의 `58.dp`·설정 액션 숨김과 충돌. 사용자 승인한 원본 시각 재현 기준에 따라 `60.dp` 및 실제 노출 구조 적용. 원본 HTML 수정 없음. 시스템 상태 표시줄·내비게이션 바는 Android 운영 영역으로 별도 유지.

- **단일 열 Compact 셸**: 기본 모바일 전체 폭, 폴더블 펼침(Medium) 시 중앙 정렬 최대 폭 `760.dp`.
- **상단 앱바 (`minHeight = 58.dp`, `paddingH = 16.dp`)**:
  - **홈 · 과거 · 지역 탭**:

## 2. 화면별 상세 레이아웃 계약

### 2.1 홈 탭 (`ui/home/`)

세로 스크롤(`LazyColumn`) 순서: **상태 배너(조건부) → Hero 스테이지(+미세먼지 1안) → 어제 비교 스트립 → 48시간 시간별 예보 → 11일 주간 예보**.

#### ① 상태 배너 (조건부 상단 노출)
- `오프라인 캐시`: 경고색(`statusWarn*`), `"N분 전 자료 · 오프라인\n마지막 저장 자료를 표시합니다."` + 우측 `재시도` 인라인 버튼.
- `조회 한도 초과`: 오류색(`statusErr*`), `"오늘 조회 한도를 초과했습니다.\n마지막 저장 자료를 유지합니다."` (재시도 버튼 없음).
- `위치 권한 꺼짐`: 경고색(`statusWarn*`), `"위치 권한이 꺼져 있습니다.\n지역 검색으로 동네 날씨를 확인할 수 있습니다."` + 우측 `설정` 버튼(탭 시 `설정 › 위치` 섹션으로 스크롤 이동).

#### ② Hero 스테이지 (`hero-stage`, 패딩 `top 8.dp, horizontal 16.dp, bottom 16.dp`)
- **배경 레이어 (3층 Z-Stack)**:
  1. `z = 0`: 상단 `hero{Sky}Start` → 하단 `ground` 수직 그라데이션 + **C안 순수 Compose `Canvas` 2D 파티클**([DESIGN_TOKENS.md](DESIGN_TOKENS.md) 6절 파라미터). 고대비·애니메이션 배율 0·스크롤 이탈(`> 320.dp`)·탭/앱 이탈 시 즉시 정지.
  2. `z = 1`: 텍스트 보호 스크림(`heroScrimTop` → `heroScrimBottom` 92%).
  3. `z = 2`: 전경 콘텐츠.
- **1차 현재 날씨 행 (`Row`, `SpaceBetween`, `CenterVertically`)**:
  - 좌측: 현재 기온(`heroTemp`, `tabularNums`) / 하늘상태 + `최고 N° · 최저 N°` / 보완 안내 `하늘상태: 예보 보완 (HH:00 유효)`.
  - 우측: 날씨 심볼 아이콘 `66.dp`.
- **보조 지표 2×2 격자 (`top 14.dp`, 상단 `1.dp borderSubtle`, `gap 10.dp × 12.dp`)**:
  - 항목 4개: `습도(%)` · `풍속 · 풍향(방향 N.Nm/s 또는 관측 없음)` · `1시간 강수(N.Nmm 또는 강수 없음)` · **`계산 체감온도 ⓘ`**(클릭 가능 버튼, 결과값 또는 `적용 범위 밖` / `자료 부족`, 탭 시 ENH-006 상세 시트).
  - 200% 글자 확대 시 **1열**로 재배치.
- **기상청 실황 메타 행 (`top 8.dp`)**:
  - 클릭 버튼(`minHeight = 32.dp`): `기상청 실황 · HH:00 자료 · 방금 갱신/N분 전 수신` + 만료/오프라인 시 `오래됨` 배지 + `ⓘ` (탭 시 ENH-001 자료 상세 시트).
- **미세먼지 히어로 하단 통합 1안 (`top 10.dp`, `paddingTop 11.dp`, 상단 `1.dp borderSubtle`)**:
  - 하단 별도 미세먼지 카드는 두지 않고 이 구획으로 일원화.
  - **독립 오류 상태**: 이 구획만 `section-error-box`(`"미세먼지 측정 자료 없음 · 근접 측정소 응답 오류"` + `재시도`)로 치환, 위 실황은 유지.
  - **2순위 측정소 대체 시**: 상단에 `air-fallback-note` 1줄 경고 박스 표시.
  - **정상 2열 클릭 버튼**: 좌 `미세먼지 (PM10)` + 등급 칩(`기호+텍스트`) + 수치 `µg/m³` | 우 `초미세먼지 (PM2.5)` + 등급 칩 + 수치 `µg/m³`. 320dp·200% 확대 시 **1열** 리플로. 탭 시 ENH-005 `최근 측정 추이` 시트 오픈.
  - **하단 출처/진입 행 (`Row`, `SpaceBetween`)**:
    - 좌측 버튼: `{측정소명} · 에어코리아 HH:00 · 확정 전` + (`오래됨` 배지) + `ⓘ` → ENH-001 미세먼지 자료 상세 시트.
    - 우측 버튼: `최근 추이 ›` → ENH-005 추이 시트.

#### ③ 어제 비교 스트립 (`surfaceCard`, 전체 클릭 + 우측 `›`)
- 상단: `어제와 비교 · 최근 10일` + `›`.
- 헤드라인: `"오늘 최고기온은 어제보다 N.N℃ 높음/낮음/비슷"`.
- 델타 알약 2개: `▲/▼ 최고 ±N.N℃` (`tempWarm`/`tempCool`), `최저 ±N.N℃`.
- 출처 1줄: `오늘(예보) · 어제({관측소명} 기상관측소 관측 · 약 N.Nkm)`. 탭 시 `과거` 탭 이동.

#### ④ 시간별 예보 48시간 (`surfaceCard`)
- 헤더: `시간별 예보 (48시간)` + 출처 버튼(`기상청 예보 · HH:00 발표 ⓘ`) + 좌우 스크롤 보조 버튼 `‹`/`›` (`32.dp`).
- **ENH-004 예보 한 줄 요약**: `tonal` 바탕 1줄 클릭 버튼(`"{H}시 예보 · 강수확률 N% · 예상 강수량 1~4mm"` + `›`, 요약 불가 시 `"예보 요약 자료 없음"` + `재시도`). 탭 시 해당 시각 ENH-003 상세 시트 오픈.
- **가로 스크롤 캔버스 (`LazyRow` 또는 동기화 `horizontalScroll`)**:
  - 상단 칸 행: 각 `60.dp` 폭 버튼(`시각` · `초단기` 태그(6시간 이내) · `24.dp` 아이콘 · 정수 기온). 현재 시각 `tonal`, 선택 시각 `accentSoft` + `1.dp accentPrimary` 테두리.
  - 중단 기온 곡선: `44.dp` 높이 `Canvas` 폴리라인(`2.2.dp accentPrimary`) + 각 시각 원형 점(선택 시각 `5.dp` 채움, 비선택 `2.8.dp` `surface` 채움).
  - 하단 강수확률 행: 각 `60.dp` 칸(`💧N%` 또는 `0%`).

#### ⑤ 주간 예보 11일 (`오늘 ~ +10일`, `surfaceCard`)
- 헤더: `주간 예보 (오늘 ~ +10일)` + 출처 버튼(`단기 HH:00 · 중기 HH:00 발표 ⓘ`).
- 행 목록(`paddingH = 0`, `borderTop = 1.dp borderSubtle`, `P8` 정렬선 일치):
  - 기본 5열: `요일+날짜(74.dp)` · `아이콘+확률(72.dp, +8~+10일은 "종일 N%")` · `최저(32.dp 우정렬)` · `비례 온도 범위 막대(1fr, 높이 7.dp, cool→warm 그라데이션)` · `최고(32.dp 좌정렬)`.
  - 320dp: `60/58/28/1fr/28`. 200% 확대: 2단 그리드(1행 요일+하늘, 2행 최저+막대+최고).
  - 중기 오류 시: `+4일~+10일` 구간만 인라인 오류 박스 + `재시도`로 치환(단기 `+3일` 유지).
  - 행 탭 시 ENH-003 일자 상세 시트 오픈.

### 2.2 과거 탭 (`ui/history/`)

세로 스크롤(`padding = 14.dp 16.dp`, `gap = 16.dp`):

1. **어제와 비교 (`surfaceCard`)**:
   - 표 5열(`구분 · 최고 · 최저 · 일평균 · 일강수`), `tabularNums`, 첫 열 좌정렬·숫자 열 우정렬.
   - 오늘 행: 최고·최저는 예보 표시, 일평균·일강수는 `미확정`(1시간 실황 대체 금지).
   - 어제 행: 관측소 일자료 전체 수치.
   - 하단 델타 2개 + 두 문장 줄바꿈 각주(`P4`).
2. **최근 10일 날씨 추이 (`surfaceCard`)**:
   - 조회 창: KST `오늘-10일 ~ 어제` (양 끝 포함 10개 날짜).
   - 빠른 선택 칩 3개: `1주` · `10일`(기본) · `직접 선택`.
   - 시작일·종료일 입력 2열(320dp/200% 시 1열) + 우측 `조회` 채운 주 버튼 + 범위 위반 시 입력 바로 아래 인라인 오류(`statusErr*`).
   - **복합 그래프 (`210.dp` 높이, Vico 또는 Compose `Canvas`)**: 최고기온 선(`tempWarm`) · 최저기온 선(`tempCool`) · 사이 연한 면(`accentPrimary` α10%) · 일강수량 막대(`rainColor` α45%, 결측 `null`은 막대 생략).
   - **유효 일수 요약 박스 (`tonal`)**: 기온 유효 일수, 최고/최저 극값 및 날짜, 유효 누적 강수량(결측 일수 제외 명시).
   - **일별 관측 목록 (`flatList`, `P6`·`P8`)**: 위·아래 `1.dp borderStrong`, 행 사이 `1.dp borderSubtle`, 좌우 여백 `0`, 행당 `날짜 · 최저/최고 · 강수량(또는 강수 결측) ›`. 탭 시 날짜 상세 시트.

### 2.3 지역 탭 (`ui/locations/`)

**P6(상자 대신 선) · P7(입력창 밖 분리) · P8(정렬선 일치)** 전면 적용(`padding = 14.dp 16.dp`, `gap = 16.dp`):

1. **지역 검색**:
   - 묶음 제목 `지역 검색` + 우측 `오프라인 검색`.
   - 입력 행: 검색 입력창(`minHeight = 44.dp`, `surface` 바탕, `1.dp borderStrong`) + 입력값 존재 시 바깥 우측에 `지우기` 텍스트 버튼(입력창 내부 버튼 금지, `P7`).
   - 2글자 이상 입력 시 `flatList`(상하 `1.dp borderStrong`, 사이 `1.dp borderSubtle`)로 결과 출력: 좌측 전체 클릭 영역(지역명 최대 2줄 말줄임 + `하늘 · 기온`, `contentDescription`은 전체 이름 `P11`) + 우측 조밀 외곽선 버튼 `추가`(저장됨 시 비활성).
2. **현재 위치**:
   - 묶음 제목 `현재 위치` + `flatList` 1행: `현재 위치 자동 인식` (`사용 중` 알약) + 상태 1줄 + 우측 조밀 외곽선 버튼(`안내`, 거부 시 `설정`으로 `설정 › 위치` 바로 이동).
3. **즐겨찾기**:
   - 묶음 제목 `즐겨찾기` + 우측 `N / 10 · 별표는 위젯 대표`.
   - `flatList` 행(`paddingH = 0`): 좌측 클릭 영역(지역명 + `대표` 알약 + `표시 중` + `전체주소 · 기온 · 하늘`) + 우측 아이콘 묶음(`별표` 대표 지정 + `휴지통` 위험색 삭제, `edgeIconOffset = -12.dp`로 시각 끝 정렬 `P8`, 터치 `44.dp` 유지 `P9`).
   - 삭제 시 스낵바 `되돌리기`(연속 삭제 Undo 스택으로 기존 순서·대표 여부 복원, 마지막 항목 삭제 시 대표 미지정 `null`).

#### 설정 행 실측 1줄/2줄 자동 배치 (`P7` Compose 구현 계약)
- 대상 행: `테마`, `색상`, `글씨 크기`, `대표 지역`, `저장된 날씨 자료`.
- **구현 방식**: 고정 화면 폭 분기 금지. Compose `Layout` 또는 `SubcomposeLayout`으로 **텍스트 실제 폭(`label` 및 `desc` 상한 `120.dp`) + 조작 요소 자연 폭 + `12.dp` 간격**을 측정해 `maxWidth` 이내면 **1줄 좌우 배치(기본)**, 초과할 때만 **2줄 수직 배치(조작 요소 좌측 시작선 정렬 · 세그먼트는 전체 폭 확장, 4색 세그먼트는 320dp/`아주 크게`/`200%`에서 2×2 그리드)**.

## 3. 바텀시트 · 문서 창 · Glance 위젯 규격

### 3.1 공통 바텀시트 / 대화상자 계약 (`P11 · P13 · P14`)
- **배경 막**: 라이트·다크 동일 `scrimModal`(`rgba(15,23,42,0.56)`), 상태 표시줄 아이콘 밝게 고정.
- **시트 컨테이너**: `surface`, `radiusSheet(20.dp)`, `padding = 18.dp`, 최대 높이 화면의 `88%`, 내부 스크롤 가능.
- **배율 상속**: 앱 글씨 크기 배율을 시트 내부에 `CompositionLocalProvider`로 재전달(`P13`).
- **헤더·닫기**: 좌측 제목(`sheetTitle`), 우측 닫기 `×` 버튼(`44.dp`, 우측 `-10.dp` 정렬). 배경 탭·시스템 뒤로 가기 닫기 + 호출 항목 초점·스크롤 복원.
- **날짜 표기(`P11`)**: 상세 시트 내부는 상대 표현(`오늘`/`어제`) 대신 정확한 날짜·시각(`YYYY-MM-DD HH:mm`) 표시.

### 3.2 시트 · 문서 창 카탈로그
1. **자료 출처 상세 (ENH-001)**: 항목명(보조색) + 값 세로 목록(`출처 · 자료 성격 · 발표/측정 시각 · 적용 구간 · 수신 시각 · 기준 지역/측정소 · 상태 · 사유`) + `확인`.
2. **시간별 상세 (ENH-003)**: 2×2 KV(`예상 기온 · 하늘/강수형태 · 강수확률 · 예상 강수량(정성/범위 원형 보존)`) + 출처/발표 시각/병합 안내 + 좌측 `이전`/`다음` 시각 이동 + 우측 `확인`.
3. **주간 일자 상세 (ENH-003)**: 최저/최고 + 오전·오후 또는 `종일`(8~10일) + 출처/발표 시각 + 해상도 안내 + 48시간 이내 날짜 한정 `시간별 보기` 보조 버튼 + `확인`.
4. **미세먼지 최근 측정 추이 (ENH-005)**: 측정소·실제 건수·기간·`µg/m³` + `184.dp` 2선 차트(PM10 `accentPrimary`, PM2.5 `pm25Line`, **결측 구간 선 끊김**) + 가로 시각 선택 칩 + 선택 시각 PM10/PM2.5 수치·등급·결측 사유 + `24:00` 정규화 표기 + 비확정 안내 + `확인`.
5. **계산 체감온도 상세 (ENH-006)**: 계산 결과·적용 계절·입력 실황값(기온·습도 또는 풍속 m/s 및 km/h) + 기준 시각·적용 범위 + 공식/한계 안내 + `확인`.
6. **과거 날짜 상세**: 관측소·거리 + 2×3 KV(`평균·일강수·최고·최저·평균풍속·평균습도`, 결측 `결측` 표기) + `확인`.
7. **위치 사용 안내 / 저장 자료 삭제 확인**: 삭제 확인 창의 확인 버튼(`삭제`)만 `destructive` 채움 사용.
8. **문서 창 4종 (본 절의 문서 창 계약)**:
   - `도움말`(홈 `?`와 설정 진입 동일 창) · `이용 안내` · `개인정보 처리방침`(**한눈에 보기 → 보관 정보 → 연결하는 곳 → 사용하는 권한 → 정보 지우기** 고정 순서) · `오픈소스 라이선스`(접이식 목록: 이름·라이선스·`›` 회전 → 저작권자·한 줄 설명).
   - 모든 문서 창 맨 끝 옅은 글자 `시행일: YYYY-MM-DD`, 하단 채운 주 버튼 `확인` 1개.
9. **Glance 홈 위젯 (`widget/`)**:
   - `radiusWidget(22.dp)`, `padding = 16.dp`, `surface`, `1.dp borderSubtle`.
   - 대표 지역 지정 시: 지역명 + `widgetTemp` 기온 + 하늘/최고/최저 + 우측 `48.dp` 아이콘 + 하단 구분선 아래 상태(`약 1시간마다 자동 갱신` 또는 `갱신 지연 · 마지막 성공 자료 유지`) 및 `마지막 성공 HH:mm`. 탭 시 **위젯 대표 지역 홈**으로 이동.
   - 대표 지역 미지정 시: `"대표 지역이 지정되지 않았습니다"` + `"대표 지역 선택 ›"` → `지역` 탭 이동.
   - 시스템 글자 배율 180% 이상: 동일 글자 역할·전체 정보를 유지하는 세로 스크롤 배치. 최소 240×200dp에서 마지막 성공 시각까지 도달 가능해야 하며, 잘림을 숨기기 위한 글자 축소 제외. 기존 Glance `LazyColumn` 사용([Android 공식 스크롤 위젯 안내](https://developer.android.com/develop/ui/compose/glance/build-ui#use-scrollable-layouts)), 라이브러리·갱신 정책·딥링크 변경 없음. 기본 배율은 고정 요약 카드 유지.

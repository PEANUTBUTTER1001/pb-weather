## 2. 배경과 문제

- 기존 날씨 앱은 **과거 날씨 조회 불가**. 어제·작년 같은 날과의 비교, 기간별 추이 확인 수단 부재.
- 기온·예보·미세먼지·과거 자료가 **여러 앱·웹에 분산** → 확인 시간 증가.
- 광고 노출·유료 기능 등 **비용 부담**.
- 근거: 사용자 인터뷰(Wizard 1차 답변) — pain_points `scattered`, `cost`, 직접 입력 "과거 날씨 조회가 안 됨".

## 5. 운용 개념

- 사용자는 하루 여러 번 앱 또는 홈 위젯으로 현재 날씨·오늘/내일 예보 확인.
- 외출 전 미세먼지 확인, 필요 시 과거 날씨 탭에서 어제·작년 비교 및 기간 그래프 확인.
- 모든 데이터는 기기에서 공공 API를 직접 호출해 수신(서버 없음, ADR-001), 로컬 캐시로 오프라인 표시.
- 위치는 현재 위치(대략적 위치 권한) 또는 지역 검색으로 결정, 즐겨찾기 최대 10개.

## 7. 가정·제약·의존성

- **가정**: 공공데이터포털 개발계정 활용신청 승인 완료 후 개발 착수. 1인 개인 사용 단계 트래픽은 개발계정 한도(API별 일 단위 한도, 포털 표기 확인) 이내.
- **제약**: Kotlin + Jetpack Compose(사용자 지정). 1인 개발·운영. 서버 운영 없음(MVP).
- **의존성**: 기상청 단기예보·중기예보·ASOS 일자료 API, 에어코리아 대기오염정보·측정소정보 API, Google Play services location, 기상청 격자 좌표표·ASOS 지점표(앱 내장).
- **위험**: 공개 배포 시 서비스 키 공유 트래픽 한도 초과(OPEN-001), 위치정보법 적용 여부(OPEN-002).

## 10. 사용자 흐름과 상태

1. **최초 실행**: 위치 사용 목적 안내 → 대략적 위치 권한 요청 → 허용 시 홈 표시 / 거부 시 지역 검색.
2. **일상 확인**: 앱 실행 → 캐시 즉시 표시 → 백그라운드 갱신 → 섹션별 갱신 완료.
3. **과거 날씨**: 홈 비교 요약 탭 또는 하단 '과거' 탭 → 기간 선택 → 그래프 → 날짜 상세.
4. **지역 전환**: 위치 버튼 → 검색 → 선택 → 즐겨찾기 저장.
5. **위젯**: 홈 화면 위젯 확인 → 탭 시 앱 홈.

| 상태 | 표시 |
| --- | --- |
| 로딩(캐시 없음) | 스켈레톤 + 진행 표시 |
| 갱신 중(캐시 있음) | 기존 값 + 상단 진행 표시 |

| 섹션 오류 | 해당 섹션만 오류 문구 + 재시도 |

## 11. 기능 요구사항

### FR-001 현재 날씨 표시 (P0)
선택 위치 격자(nx, ny)로 기상청 초단기실황 조회 → 기온·습도·풍속·풍향·1시간 강수량·강수형태·발표 시각 표시.
- AC-FR-001-1: 홈 진입 시 현재 기온·습도·풍속·강수형태·발표 시각 표시.
- AC-FR-001-2: base_date·base_time은 선택 API 최신 공식 가이드와 실응답으로 계산. 261019 가이드의 10분 간격·10분 지연을 우선 적용하고 NO_DATA에서 구 시간 단위 호환 시각으로 1회 재시도. 실제 응답 자료 시각 유지(API_CONTRACT 참조).

### FR-002 시간별 예보 (P0)
단기예보 + 초단기예보 결합, 1시간 간격 기온·하늘상태·강수확률·강수량 가로 목록.
- AC-FR-002-1: 현재 시각 이후 최소 48시간 표시.
- AC-FR-002-2: 단기예보는 02·05·08·11·14·17·20·23시 발표 중 최신 가용 발표 사용, 6시간 이내는 초단기예보 값 우선.

### FR-003 주간 예보 (P0)
오늘~+10일 일별 최저·최고기온, 오전·오후 하늘상태·강수확률. 단기예보 범위는 단기예보, 이후는 중기육상예보·중기기온.
- AC-FR-003-1: 오늘~+10일 최저·최고·강수확률 빈칸 없음.
- AC-FR-003-2: 위치 → 중기 육상예보 구역 코드·중기기온 지점 코드 매핑, 실패 시 구간에 사유·재시도 표시.

### FR-004 미세먼지·초미세먼지 (P0)
에어코리아 근접 측정소 → 측정소별 실시간 측정정보, PM10·PM2.5 농도와 등급.
- AC-FR-004-1: 수치와 등급(좋음·보통·나쁨·매우나쁨)을 텍스트+아이콘으로 표시.
- AC-FR-004-2: 측정소명·측정 시각 표시, 결측('-')·점검 시 '측정 자료 없음' 및 다음 근접 측정소 재조회.

### FR-005 어제 비교 (P0)
최근접 ASOS 지점 일자료로 어제의 평균·최고·최저기온, 일강수량 조회 후 오늘 값(실황·예보)과 차이 표시.
- AC-FR-005-1: 최고·최저기온, 일강수량과 오늘 대비 차이(예: "어제보다 3.2℃ 높음") 표시.
- AC-FR-005-2: 관측소명·지역 기준 거리(km) 표시. 오늘 최고·최저는 예보, 어제는 관측으로 구분. 작년 비교는 후속 이연.

### FR-006 최근 10일 기간 조회·그래프 (P0)
시작·종료일 선택 → 일별 최고·최저기온 선 그래프 + 일강수량 막대 그래프, 날짜 탭 시 상세.
- AC-FR-006-1: KST 오늘-10일부터 어제까지 양 끝 포함 최근 10일 창 안에서 선택, 역전·범위 위반 시 입력 근처 오류 문구.
- AC-FR-006-2: 1주·10일·직접 선택, 날짜 상세(평균·최고·최저기온, 일강수량, 평균풍속, 평균습도).

### FR-007 현재 위치 자동 인식 (P0)
ACCESS_COARSE_LOCATION으로 위치 획득 → 격자·ASOS 지점·측정소·중기예보 구역 변환.
- AC-FR-007-1: 허용 시 위경도 → 기상청 Lambert 정각원추도법 격자(nx, ny) 변환 후 조회.
- AC-FR-007-2: 거부·위치 서비스 꺼짐 시 앱 종료 없이 사유 안내와 지역 검색 이동.

### FR-008 지역 검색·즐겨찾기 (P0)
내장 행정구역 격자표로 시·군·구·읍면동 검색, 즐겨찾기 저장·삭제·전환·대표 지정.
- AC-FR-008-1: 2글자 이상 입력 시 0.3초 이내 결과, 선택 시 날씨 전환.
- AC-FR-008-2: 즐겨찾기 최대 10개, 삭제 직후 스낵바 '되돌리기'로 복구.

### FR-009 홈 화면 위젯 (P0)
Glance 위젯 — 대표 위치 현재 기온·하늘상태·오늘 최고/최저·갱신 시각.
- AC-FR-009-1: 위 정보 표시, 탭 시 앱 홈 열림.
- AC-FR-009-2: WorkManager 60분(최소 30분) 주기 갱신, 실패 시 마지막 성공 값·시각 유지.

### FR-010 오프라인 최근 날씨 (P0)
마지막 성공 데이터 로컬 저장, 네트워크 없을 때 표시.
- AC-FR-010-1: 비행기 모드 실행 시 마지막 데이터 + 'N분 전 자료 · 오프라인' 배너.
- AC-FR-010-2: 캐시 없음 시 원인·재시도 버튼이 있는 빈 상태.

## 12. 비기능 요구사항

### NFR-PERF-001 표시 속도와 API 호출 절감 (P0)
- AC-NFR-PERF-001-1: 콜드 스타트 후 캐시 1초 이내, 네트워크 갱신 3초 이내(p90, Wi-Fi).
- AC-NFR-PERF-001-2: 동일 위치·base_date/base_time 조합은 캐시 유효 기간 내 재호출 금지, 과거 일자료는 받은 날짜 재호출 금지.

### NFR-PERF-002 배터리·데이터 사용 절제 (P1)
- AC-NFR-PERF-002-1: 백그라운드 갱신은 네트워크 제약 WorkManager 주기 작업만 사용, 정밀 위치 요청 없음.
- AC-NFR-PERF-002-2: 전체 갱신 1회 전송량 500KB 이하.

### NFR-A11Y-001 접근성 기본 기준 (P0)
- AC-NFR-A11Y-001-1: 아이콘·그래프·등급에 contentDescription, TalkBack으로 주요 값 낭독.
- AC-NFR-A11Y-001-2: 글자 크기 200%에서 핵심 정보 잘림 없음, 텍스트 대비 4.5:1 이상.

## 13. 데이터·보안 요구사항

### DATA-001 로컬 저장·캐시 수명 규칙 (P0)
- AC-DATA-001-1: 실황 30분·시간별 3시간·주간 12시간·미세먼지 1시간 만료, 만료 데이터는 갱신 중·오프라인·온라인 오류·한도 초과에도 원래 시각·오래됨 상태와 함께 표시, 만료 시각 연장 금지.
- AC-DATA-001-2: 과거 일자료 무기한 보관, 전체 캐시 50MB 초과 시 오래 조회하지 않은 항목부터 삭제.

### DATA-002 외부 데이터 출처·자료 성격 표기 (P0)
- AC-DATA-002-1: 정보 화면에 기상청·한국환경공단(에어코리아) 출처와 이용 조건 표시.
- AC-DATA-002-2: 미세먼지 영역에 '실시간 자료는 확정 전 자료로 변동될 수 있음' 안내.

### SEC-001 위치정보 최소 처리 (P0)
- AC-SEC-001-1: 매니페스트에 ACCESS_FINE_LOCATION·ACCESS_BACKGROUND_LOCATION 없음, ACCESS_COARSE_LOCATION만 선언.
- AC-SEC-001-2: 로그·크래시 리포트·캐시 키에 원본 위경도 미기록(격자·지점 ID만 사용).

### SEC-002 공공데이터 서비스 키 보호 (P0)
- AC-SEC-002-1: 서비스 키는 local.properties(Git 제외) → BuildConfig 주입, 저장소 키 문자열 검색 0건.
- AC-SEC-002-2: release 빌드 R8 축소·난독화 활성.

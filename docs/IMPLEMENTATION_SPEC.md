# 요구사항 명세서

## 1. 작업 개요

- 작업명: PB Weather v1 및 확정 고도화 구현.
- 목적: 공공 API 기반 현재·예보·최근 과거·대기질 통합 앱과 홈 위젯 구현.
- 요청 근거: 2026-11-24 사용자 지시 «권장안 반영 구현 계획 /srs» 및 namespace 정정 후 /execute 실행 지시.
- 승인: SRS 계획 제시 후 2026-11-24 사용자 /execute 명시 호출로 구현 승인. namespace/applicationId는 com.pbweather.weather로 정정.

## 2. 구현 범위

### 포함

- FR-001~010의 ENHANCEMENT_GUIDELINE 2절 적용 범위, ENH-001~006 전부.
- 프로젝트 독립 Git, `.gitignore` 직접 관리, 빌드·테마·로컬 저장·API·화면·위젯·검증.
- 최근 10일, 어제 비교, 미래 오늘~+10일, 4탭, 4색×라이트/다크 및 고대비.
- 출처·시각·정성값·결측 보존, 지역 응답 경쟁 방지, 요청 공유, 섹션 독립 실패.
- C안 Canvas, 미세먼지 히어로 통합, 48시간/일자/대기질/체감온도 상세.
- 기존 문서 충돌 정리, 강수 텍스트 대비 보강, 검색 조기 연결, 실기기 검증 기록.

### 제외

- 작년 비교·366일·장기 조회, 서버/프록시, 새 데이터 서비스, 푸시·광고·분석 SDK.
- 릴리스 키 생성·접근, 서명·Play 업로드·공개 배포(TASK-014 별도 승인).

## 3. 기능 요구사항

1. 캐시를 즉시 표시하고 만료 섹션만 갱신. 오류 시 값·성공 시각 유지.
2. COARSE 단발 위치를 격자·공개 지점으로 변환. 거부 시 오프라인 지역 검색.
3. 현재·시간별·주간 예보를 실제 제공 필드와 시각 단위로 병합. 미제공 보간 금지.
4. ASOS 최근 10일 창과 어제 비교. 오늘 일평균·일강수는 미확정.
5. PM별 독립 결측, 1시간 농도/등급, 실제 최대 24건 추이·측정소 대체.
6. 예보 6개 최대 POP/동률/결측 규칙에 따른 한 줄 요약.
7. 같은 실황 시각 입력으로 계절별 계산 체감온도. 겨울 WSD 규격 미확인 시 미완료.
8. 즐겨찾기 10개·Undo·대표 최대 1개/없음·위젯 대표 딥링크 일관성.
9. 설정 즉시 저장, 자료 삭제 시 설정·자산 보존, 출처·도움말·개인정보·라이선스 표시.

## 4. 입력·출력 및 인터페이스

- 입력: 공공 API 5종, 내장 공식 자산, COARSE 위치, 지역·날짜·설정 선택.
- 출력: StateFlow UI, Room Flow, DataStore 설정, Glance 위젯, 검증 증거.
- 기존 계약 영향: REQUIREMENTS/ARCHITECTURE/TEST의 이전 과거 범위·대표 필수·만료 표시·출시 완료 조건 정합화.
- 원본 사용자 좌표 전송 금지. 공개 측정소 목록을 로컬 매핑하며 요청에는 측정소명만 사용.

## 5. 예외 및 경계 상황

- 캐시 유무·온라인 실패·오프라인·한도·키 오류·XML 오류·타임아웃·부분 실패.
- KST 자정·발표 지연·최근 10일 경계·역전 날짜·미게시 ASOS 날짜.
- 지역 전환 중 응답·대표 삭제/연속 Undo·앱 재시작·위젯 지연.
- 강수 범위/정성값·PM별 결측·24:00·동일 시각 중복·불연속 시계열.

## 6. 비기능 요구사항 및 제약

- Kotlin/Compose, 단일 app, Hilt·Retrofit/OkHttp·Room·DataStore·WorkManager·Glance 기본 스택.
- 기본 스택 채택은 사용자 권장안 반영 승인 범위. 정확한 버전은 카탈로그 및 API_CONTRACT에 고정.
- 차트/파티클은 Compose Canvas, 신규 시각화 SDK 추가 없음.
- 키는 빌드 과정만 주입. Agent의 local.properties/서명 파일 읽기·수정·출력 금지.
- API 26+, 주입 Clock(KST), 토큰·strings.xml, TalkBack, 320/375dp·200%·다크·고대비.
- 50MB LRU, 실황30분/시간별3시간/주간12시간/AIR1시간. 만료 성공 자료는 상태 병기 후 유지.

## 7. 가정 및 확인 필요 사항

### 가정

- 임시 namespace/applicationId `com.pbweather.weather`, 표시명 땅버날씨/PB Weather.
- 기본 스택과 권장 보완 승인 적용. 기능/권한 범위 확대 없음.

### 확인 필요

- API 신청·키 유효성과 S25 Ultra 연결은 실제 검증으로 확인. 실패를 성공으로 기록 금지.
- 중기 선택 API 실제 제공 범위와 겨울 WSD 평균시간은 공식 가이드·실응답으로 확인.
- 원격 저장소는 신규 로컬 저장소에 설정 없음. 상위 Documents 원격 사용 금지.
